# Лисичка ИИ

Нативное Android-приложение личного ИИ-помощника на Kotlin и Jetpack Compose.

## Сборка
Релизы и APK собираются автоматически через GitHub Actions при каждом push в `main`.
Последний APK доступен в разделе [Releases](../../releases).

## Версия
Текущая версия разработки хранится в корневом файле `VERSION`.

## История изменений
`CHANGELOG.md` — единый источник описания изменений, который публикуется вместе с каждым релизом.
При каждом изменении исходников обновляйте этот файл.

## Технологии
- Kotlin
- Android SDK
- Jetpack Compose
- Material 3

## Статус
Начальный интерфейс. Интеграция AnyModel, безопасное хранение API-ключа, долговременная память и голосовой режим будут добавляться последовательно.
