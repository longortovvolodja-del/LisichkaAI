# История изменений — Лисичка ИИ

## 1.0.5 — Неоновый дизайн и новый образ Лисички
### Добавлено
- Обновлённая тёмная тема с фиолетово-синими градиентами и неоновыми акцентами.
- Более выразительное приветствие, оформление сообщений и панели ввода.
- Новый векторный значок приложения с мордочкой Лисички и фиолетово-синим фоном.
- Иллюстрация Лисички в шапке приложения и на приветственном экране.

### Изменено
- Навигация, карточки памяти и основные элементы интерфейса приведены к единой визуальной палитре.

### Исправлено
- Значок приложения больше не использует стандартную иконку Android.


Этот файл является единственным источником описания изменений для GitHub Releases.
При каждом изменении приложения добавляй в начало раздел с датой и списками:
- Добавлено
- Изменено
- Исправлено

Не записывай в историю то, чего нет в исходном коде. Workflow прикладывает содержимое этого файла к каждому релизу.

## 1.0.4 — Долговременная память и форматирование сообщений
### Добавлено
- Долговременная память на устройстве с зашифрованным хранением записей.
- Передача сохранённых воспоминаний в системный контекст ИИ для использования в следующих разговорах.
- Автоматическое выделение устойчивых фактов из диалогов с исключением паролей, ключей и чувствительных сведений.
- Экран управления памятью: добавление, редактирование, удаление отдельных записей и полная очистка.
- Переключатель автоматического запоминания.
- Отображение Markdown: жирный, курсив, зачёркивание, встроенный код, заголовки и маркированные списки.

### Изменено
- Ответы ассистента отображаются с форматированием вместо сырых маркеров Markdown.

### Исправлено
- Память больше не теряется при закрытии приложения.

## 1.0.3 — Автоматическое озвучивание ответов
### Добавлено
- Переключатель автоматического озвучивания ответов ИИ в настройках; по умолчанию выключен.
- Синтез речи через AnyModel /v1/audio/speech с выбранной моделью голоса.
- Воспроизведение полученного аудио внутри приложения и кнопка остановки текущей озвучки.
- Отдельное поле для ID модели голоса, по умолчанию edge-tts/ru-RU-SvetlanaNeural.

### Изменено
- Настройка озвучивания сохраняется на устройстве и использует существующий API-ключ AnyModel.

### Исправлено
- Отключение автоматического озвучивания останавливает текущую речь.

## 1.0.2 — Исправление переключения экранов и защита API-ключа
### Изменено
- Состояние вкладок сохраняется при переключении между чатом, памятью и настройками.
- Состояние полей настроек, загруженного списка моделей и прокрутки восстанавливается при возвращении на экран настроек.
- API-ключ теперь скрыт в поле ввода по умолчанию; его можно временно показать отдельной кнопкой.

### Исправлено
- Переключение вкладок больше не должно сбрасывать загруженный список моделей и введённые, ещё не сохранённые настройки.
- Экран памяти теперь явно сообщает, что долговременное сохранение переписок ещё не реализовано.

## 1.0.1 — Подключение AnyModel и настройка поведения
### Добавлено
- Подключение чата к OpenAI-совместимому API AnyModel через /v1/chat/completions.
- Проверка API-ключа и загрузка доступных моделей через /v1/models.
- Выбор модели из автоматически загруженного списка и ручной ввод ID.
- Редактируемые профили системных инструкций: Лисичка, универсальный помощник, программист, творческий режим и учитель.
- Сохранение Base URL, модели и системного промпта.
- Локальное зашифрованное хранение API-ключа средствами AndroidX Security Crypto.

### Изменено
- Сообщения из чата теперь отправляются в выбранную модель AnyModel.
- Экран настроек разделён на подключение, выбор модели и системный промпт.

### Известные ограничения
- Ответы пока загружаются целиком, без потоковой печати токенов.
- История чата пока хранится только в памяти текущего запуска приложения.
- Голос, вложения и долговременная память ещё не реализованы.
- Для использования необходим собственный API-ключ AnyModel и доступный баланс/лимит у провайдера.

## 1.0.0 — Первый прототип
### Добавлено
- Начальный Android-проект на Kotlin и Jetpack Compose.
- Тёмно-фиолетовый интерфейс «Лисичка ИИ».
- Главный экран чата с полем ввода и списком сообщений.
- Навигация между чатом, памятью и настройками.
- Начальный экран настроек подключения AnyModel.
